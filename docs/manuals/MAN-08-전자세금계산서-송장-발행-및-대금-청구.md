# MAN-08 · [공급업체] 전자세금계산서/송장(Invoice) 발행 및 대금 청구

> 현장에서 검수가 완료된 자재에 대하여 국세청 전자세금계산서 양식에 준하는 송장을 발행하고, 입금받을 사업자 통장 계좌를 지정하여 대금을 정식 청구합니다.

| 항목 | 내용 |
|------|------|
| 문서 코드 | `MAN-08` |
| 분류 | 공급업체 매뉴얼 |
| 대상 사용자 | 협력 공급업체 |
| 배지 | 공급업체 / 송장 청구 |
| 관련 화면 | 공급업체 > 송장/계산서 관리 > 신규 송장 |

## 단계별 표준 실행 절차 (SOP)

### 1. 검수 완료 건 선택

[송장/계산서 관리] 탭에서 자재 검수가 통과된 건(DELIVERED)을 확인합니다.

- **시스템 조작**: [신규 송장 발행] 버튼을 클릭합니다.

### 2. 공급가액 및 부가세 자동 검산

납품 수량 x 단가로 계산된 공급가액에 부가가치세 10%가 자동 가산되어 총 청구 금액이 산출됩니다.

- **시스템 조작**: 지급 기한(통상 마감일 기준 익월 말일 등)을 설정합니다.

### 3. 수금 전용 계좌 입력 후 발행 확정

공급업체의 은행명, 계좌번호, 예금주를 정확히 기재하고 [송장 청구 발행]을 완료합니다.

- **시스템 조작**: 현장 관리자에게 결제 대기 상태로 즉시 인계됩니다.
