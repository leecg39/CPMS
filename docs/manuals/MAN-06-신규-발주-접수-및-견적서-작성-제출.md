# MAN-06 · [공급업체] 신규 발주 접수 및 견적서(Quotation) 작성/제출

> 건설 현장에서 요청된 자재 발주 건을 실시간으로 확인하고, 보유 재고와 생산 일정을 고려하여 경쟁력 있는 제안 단가 및 납기 리드타임을 작성하여 견적서를 제출합니다.

| 항목 | 내용 |
|------|------|
| 문서 코드 | `MAN-06` |
| 분류 | 공급업체 매뉴얼 |
| 대상 사용자 | 협력 공급업체 |
| 배지 | 공급업체 / 견적 작성 |
| 관련 화면 | 공급업체 > 견적 관리 > 견적서 제출 |

## 단계별 표준 실행 절차 (SOP)

### 1. 견적 요청 발주 건 검색 및 상세 검토

공급업체 대시보드에서 견적 제출이 가능한 발주 목록을 확인합니다.

- **시스템 조작**: [견적 관리] 탭에서 상태가 [대기중(PENDING)]인 발주를 클릭하여 규격 및 필요 수량을 확인합니다.

### 2. 제안 단가 및 납기 일수(Lead Time) 산정

현재 원자재 시세 및 운반비를 반영한 단위당 공급 단가와 납기 소요 일수를 산정합니다.

- **시스템 조작**: 제안 단가(원/단위)를 입력하면 총액이 자동으로 계산됩니다.

### 3. 견적 유효기간 및 특약사항 기재 후 제출

견적서의 유효기간(통상 7일~14일)과 하역 조건, 포장 상태 등의 비고 사항을 입력하고 제출합니다.

- **시스템 조작**: [견적서 제출] 버튼을 누르면 발주 상태가 [견적 접수됨(QUOTED)]으로 즉시 갱신됩니다.

## 주의 사항

- 원자재 시세 급변동 위험이 있는 철강/유류 자재는 유효기간을 7일 이내로 설정할 것을 권장합니다.
