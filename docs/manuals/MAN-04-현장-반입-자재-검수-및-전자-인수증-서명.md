# MAN-04 · [현장관리자] 현장 반입 자재 검수(Inspection) 및 전자 인수증 서명

> 공급업체로부터 자재가 현장에 도착했을 때, 품질 성적서 확인, 수량 계량표 대조, 외관 손상 검사를 진행한 뒤 전자 서명으로 납품을 최종 승인하는 절차입니다.

## 단계별 표준 실행 절차 (SOP)

### 1. 도착 자재 운송 정보 확인

배송 목록에서 도착한 차량번호(예: 경기88바5678)와 자재 송장을 확인합니다.

- **시스템 조작**: [배송/검수 현황] 탭에서 해당 배송 건의 [검수하기] 버튼을 클릭합니다.

### 2. 품질 및 실물 수량 정밀 검수

공장 출하 송장의 수량과 실제 반입 물량을 대조하고 규격 일치 여부를 육안 및 계측 검사합니다.

- **시스템 조작**: 검수 결과 항목에서 [합격(PASS)] / [조건부 합격] / [불합격(FAIL)]을 체크합니다.

### 3. 현장 인수자 서명 및 검수 의견 저장

검수자 성명 입력 및 전자 인수증에 서명(또는 검수자 확인 서명 입력) 후 [검수 완료 처리]를 실행합니다.

- **시스템 조작**: 검수 완료 시 상태가 [검수 완료/DELIVERED]로 변경되며 공급업체에 송장 발행 권한이 부여됩니다.

## 주의 사항

- 철근 반입 시 밀시트(Mill Sheet, 품질보증서) 및 인장강도 시험성적서 미지참 시 불합격 처리해야 합니다.
- 수량 부족 발견 시 반드시 검수 의견란에 실측 수량을 명기하여 정산 시 차감 반영되도록 해야 합니다.
