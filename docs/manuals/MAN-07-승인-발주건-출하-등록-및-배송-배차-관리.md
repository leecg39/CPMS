# MAN-07 · [공급업체] 승인 발주건 출하 등록 및 배송(Delivery) 배차 관리

> 현장에서 승인된 발주 건에 대해 공장/창고에서 출하를 진행하고, 운송 기사 정보와 차량 번호, 출하 시간을 시스템에 등록하여 현장에 실시간 도착 정보를 제공합니다.

| 항목 | 내용 |
|------|------|
| 문서 코드 | `MAN-07` |
| 분류 | 공급업체 매뉴얼 |
| 대상 사용자 | 협력 공급업체 |
| 배지 | 공급업체 / 출하 및 배송 |
| 관련 화면 | 공급업체 > 배송/출하 관리 > 신규 출하 |

## 단계별 표준 실행 절차 (SOP)

### 1. 승인된 발주 확인

[배송/출하 관리] 탭에서 상태가 [발주 승인(APPROVED)]인 건을 선택합니다.

- **시스템 조작**: 우측 상단의 [신규 배송/출하 등록] 버튼을 클릭합니다.

### 2. 배차 정보 및 운송 기사 연락처 입력

자재를 적재한 화물차량 번호(예: 서울82아1234)와 담당 기사 성명, 휴대폰 번호를 기재합니다.

- **시스템 조작**: 운송 기사에게 현장 게이트 진입 시 유의사항을 사전에 전파합니다.

### 3. 출하 등록 및 배송 추적 개시

[출하 등록 완료]를 누르면 배송 번호(DEL-xxx)가 생성되고 상태가 [배송중(IN_DELIVERY)]으로 전환됩니다.

- **시스템 조작**: 현장 관리자 화면에 해당 차량 정보와 예상 도착 시간이 실시간 노출됩니다.

## 주의 사항

- 현장 교통 혼잡 시간대(출퇴근 및 레미콘 집중 타설 시간대)를 피해 배차 일정을 조율해야 합니다.
