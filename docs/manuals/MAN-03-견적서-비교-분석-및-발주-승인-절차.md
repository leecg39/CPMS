# MAN-03 · [현장관리자] 견적서(Quotation) 비교 분석 및 발주 승인 절차

> 등록된 발주 요청에 대해 복수의 공급업체로부터 접수된 견적(제안 단가, 납기 리드타임, 공급 조건)을 다각도로 비교 검토하여 최적 업체를 선정하고 최종 발주를 승인합니다.

## 단계별 표준 실행 절차 (SOP)

### 1. 발주 목록에서 견적 접수 건 확인

상태가 "견적 접수됨(QUOTED)"인 발주 항목을 클릭하여 상세 모달창을 엽니다.

- **시스템 조작**: 해당 발주 건에 제출된 공급사들의 견적 금액과 리드타임 목록을 조회합니다.

### 2. 견적 조건 비교 (단가 vs 납기)

최저가 제안뿐만 아니라 공사 크리티컬 패스에 지장을 주지 않는 납기 준수 가능 여부를 종합 평가합니다.

- **시스템 조작**: 단가 절감률(%)과 제안 납기일을 확인합니다.

### 3. 최적 견적 채택 및 발주 승인(Approve)

선정된 업체의 [견적 채택 및 발주 승인] 버튼을 누르면 상태가 즉시 [발주 승인(APPROVED)]으로 변경됩니다.

- **시스템 조작**: 승인 확인 팝업에서 승인 사유를 확인하고 확정합니다.

## 주의 사항

- 유효기간(Valid Until)이 지난 견적서는 채택이 불가능하며, 재견적을 요청해야 합니다.
